It has been a while since I wrote a technical blog, can't say I do a pretty good job at it, so why this blog now? Well I spent my birthday trying to dual boot Omarchy Linux with Windows 11 and it was quite a struggle. I figured I would write it down before I forget how I did it. The official manual and a youtube video I found made it look easy, but trying to do it from a macbook for an ASUS desktop was a pain.

## The problem

The official guide does have a documentation for dual boot (https://omarchy.org/manual/dual-boot-install/) however I couldn't get Omarchy detect the shrunk free space in disk and Omarchy always tried to wipe and install on my entire disk, while I wanted to dual boot it with Windows. So I ended up installing Arch linux and then installing Omarchy on it. This is what the Omarchy installation does too, but starting with Arch linux gives more flexiblity in creating partition.

## ASUS EZBoot didn't like the USB with Omarchy

The official guides suggests flashing a USB with Omarchy (using for example BalenaEtcher) and dropping into Arch linux install (by pressing Esc or Ctrl+C on the Omarchy install screen), but my ASUS motherboard completely ignored the USB. It turns out that Mac format creates a hybrid drive that strict ASUS motherboards don't see when CSM is disabled. So I had to use Ventoy.

* Download an app called Mactoy from github since Ventoy doesn't have a mac installer.
* Install Ventoy to the USB with a GPT partition style.
* Drop the vanilla Arch linux ISO into the Ventoy drive that gets mounted.

Once I did that, the F8 boot menu finally saw the Arch boot option.

## Partitioning and installation

I booted into the Arch environment, verified I was able to access the internet. NOTE: I had a wired connection, but you can also use `iwctl` to locate and connect a wifi access point from the arch shell. 

The Limine bootloader suggested for Omarchy cannot be installed in the 100MB Windows EFI partition and since it requures at least 3GB memory, the first task is to create a partition for the boot loader.

For partitioning, I used `cfdisk /dev/nvme0n1` to
* Create a 4GB EFI system partition (since Limine needs 3GB disk space).
* Then created a Linux filesystem partition with the rest of the free space.
* Formatted them with `mkfs.fat -F3` and `mkfs.btrfs` respectively.
    ```
    mkfs.fat -F3 /dev/nvme0n1p6
    mkfs.btrfs /dev/nvme0n1p7
    ```
* Mounted the root to `/mnt` and efi to `/mnt/boot`.

Then I ran `archinstall` and in the Disk configuration, I selected pre-mounted configuration pointing to `/mnt`. I used Limine for bootloader and finished the installation.

## Fixing dependencies and boot menu

After rebooting into Arch, I tried running the Omarchy install script but it failed with a 404 error for a the `gum` package. The omarchy stable-mirror was broken, so I had to manually run `sudo pacman -Syy gum` and then re-run the `curl -fsSL https://omarchy.org/install | bash` to install Omarchy.
