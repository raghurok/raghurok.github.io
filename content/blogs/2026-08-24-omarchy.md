Dual-booting [Omarchy Linux](https://omarchy.org/) alongside Windows 11 on modern UEFI hardware requires careful disk configuration. While Omarchy provides an automated installer, running it alongside an existing operating system can cause partition conflicts.

In this guide, I outline how to install a base Arch Linux system using manual partitioning and `archinstall`, and then layer Omarchy on top to create a reliable dual-boot environment.

## The Problem: Default Installer Partition Handling

The official Omarchy documentation provides a [Dual Boot Guide](https://omarchy.org/manual/dual-boot-install/). When I ran the default installer ISO, the installation script failed to detect unallocated free space on the NVMe drive. The script wiped the Windows boot partition, which I recovered before continuing.

Omarchy layers a customized desktop environment—including the Hyprland tiling window manager, themes, and curated workflows—on top of Arch Linux. Because the automated Omarchy installer assumes control of the entire disk partition table, installing a minimal base **Arch Linux** system first with manual partitioning provides greater control and prevents data loss.

---

## Step 1: Shrink the Windows Partition

Before creating installation media, allocate unpartitioned disk space in Windows:

1. Open **Disk Management** in Windows 11 by pressing `Win + X` and selecting **Disk Management**, or by running `diskmgmt.msc`.
2. Right-click the primary Windows partition (`C:`) and select **Shrink Volume...**.
3. Allocate at least 60–100 GB of space for Linux.
4. Leave this space **Unallocated**. Do not format or assign a drive letter to the new partition.

---

## Step 2: Create a Bootable USB with Ventoy and Mactoy

Standard installation guides recommend writing ISO images to a USB flash drive with tools such as BalenaEtcher or Raspberry Pi Imager. When using macOS to flash drives for an ASUS motherboard, the default flash process creates hybrid MBR/GPT partition tables. When CSM is disabled in firmware, ASUS motherboards with strict UEFI enforcement ignore these flash drives in the EZ Boot menu (`F8`).

To resolve this boot failure, use [Ventoy](https://www.ventoy.net/), an open-source tool that creates a dedicated UEFI bootloader capable of launching ISO images copied to the drive.

Because Ventoy lacks a native macOS graphic installer, use **Mactoy** to prepare the drive:

1. Download [Mactoy](https://github.com/zenf00/mactoy), a macOS graphical interface for Ventoy.
2. Insert your USB drive into your Mac and install Ventoy using the **GPT partition style** for UEFI boot compatibility.
3. Once installation finishes, macOS mounts the Ventoy storage partition.
4. Download the [Arch Linux ISO](https://archlinux.org/download/) and copy the `.iso` file to the Ventoy partition.
5. Insert the USB drive into the desktop and press `F8` during POST. Select the USB drive from the ASUS boot menu to launch Ventoy and load the Arch Linux installer.

## Step 3: Configure Network and Disk Partitions

After booting into the Arch Linux live environment, confirm network connectivity. Wired Ethernet connections configure automatically using DHCP. For wireless networks, connect using `iwctl`:

```bash
iwctl
station wlan0 scan
station wlan0 get-networks
station wlan0 connect "Your-WiFi-SSID"
exit
ping -c 3 archlinux.org
```

### EFI System Partition Size Requirements

Windows 11 creates a default EFI System Partition (ESP) sized at **100 MB**. Omarchy uses the **Limine** bootloader, which requires approximately **3 GB** of storage because it stores kernel images, initramfs images, and boot assets on the boot partition itself.

Installing Limine into the 100 MB Windows ESP will fail from disk exhaustion. You must create a dedicated ESP for Linux.

### Partition the Drive with `cfdisk`

Identify your disk device identifier using `lsblk` (such as `/dev/nvme0n1`), then launch `cfdisk`:

```bash
cfdisk /dev/nvme0n1
```

From the unallocated free space, create two partitions:
1. **EFI Boot Partition**: Size `4G`, Type `EFI System` (for example, `/dev/nvme0n1p6`).
2. **Root Partition**: Remaining free space, Type `Linux filesystem` (for example, `/dev/nvme0n1p7`).

Write the partition table changes (`write` -> type `yes`) and exit the utility.

### Format and Mount Partitions

Format both partitions and mount them to `/mnt`:

```bash
# Format the EFI partition as FAT32
mkfs.fat -F 32 /dev/nvme0n1p6

# Format the Root partition (using Btrfs or Ext4)
mkfs.btrfs -f /dev/nvme0n1p7

# Mount root to /mnt
mount /dev/nvme0n1p7 /mnt

# Create /mnt/boot and mount the EFI partition
mkdir -p /mnt/boot
mount /dev/nvme0n1p6 /mnt/boot
```

## Step 4: Install Base Arch Linux

With the partitions mounted, launch the interactive Arch installer:

```bash
archinstall
```

Select the following configuration options in `archinstall`:
* **Disk configuration**: Choose **Pre-mounted configuration** and set the mountpoint to `/mnt`.
* **Bootloader**: Choose **Limine** (installs to `/mnt/boot`).
* **Network configuration**: Choose **NetworkManager**.
* **Audio**: Choose **Pipewire**.
* **User account**: Create your primary user account and grant `sudo` administrative privileges.

Complete the installation prompts and reboot into the Arch Linux installation.

---

## Step 5: Install Omarchy and Resolve Package Dependencies

After rebooting, remove the USB installation drive and log in to Arch Linux.

Run the standard Omarchy installation script:

```bash
curl -fsSL https://omarchy.org/install | bash
```

### Resolve Missing Package Dependencies

During installation, the Omarchy script may halt with a `404 Not Found` error when fetching `gum`, a tool for interactive prompts. This failure occurs when the Omarchy package repository references an outdated mirror endpoint.

To resolve this dependency error, install `gum` from the official Arch Linux package repositories:

```bash
sudo pacman -Syy gum
```

After `gum` installs, rerun the Omarchy installation script:

```bash
curl -fsSL https://omarchy.org/install | bash
```

The script will complete the installation of Hyprland, system configuration files, themes, and desktop utilities.

## Step 6: Configure the Dual-Boot Boot Menu

The Limine bootloader automatically detects other operating systems on the drive, including Windows Boot Manager on the original Windows ESP.

Upon starting the computer:
1. Limine presents a boot menu containing entries for both **Arch Linux (Omarchy)** and **Windows 11**.
2. If the computer boots into Windows by default, enter the UEFI firmware settings (press `Del` or `F2` during startup) and set **Limine** as the first entry in the boot priority order.

---

## Summary

Dual-booting Omarchy Linux alongside Windows 11 succeeds when you bypass the default installer's automated disk partitioning:
- Create unallocated disk space in Windows Disk Management.
- Use Ventoy with a GPT partition layout to boot on strict UEFI motherboards.
- Provision a dedicated 4 GB EFI System Partition to accommodate the Limine bootloader and kernel images.
- Install base Arch Linux using `archinstall`, install `gum` from the official repositories, and run the Omarchy setup script.
